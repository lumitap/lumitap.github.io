# LumiTap

Permanent links for NFC tags. Each tag holds one link that never changes:

    https://lumitap.github.io/t/?1  …  https://lumitap.github.io/t/?10

Where each tag goes is set in `tags.json`. Change the `url` there and the tag opens the new place — no need to rewrite the tag.

- `t/` — resolves a tag number to its `url`
- `belan/` — tag 1: lost-child card (3D model "RobotExpressive" by Tomás Laulhé / Quaternius, CC0 1.0)
